# Local user-owned student-model store

Study OS reverses the charting “hybrid = remote student model” lock: **learners own their durable data**; there is **no operator-hosted student-model database** in v1. The **student model** plus **session summaries** and **evidence briefs** live in a **user-global local store** outside any single course-pack workspace. The **agent harness** is configured with a path to that store so a new workspace does not reset the learner. Peers each point at their own store (mis-pointed config is the mixing failure mode — not a shared auth service). Product learning about what fails comes from **user interviews** and voluntary exports, not a central event warehouse. v1 concrete form: a **SQLite file** per learner at the configured path (lightweight, portable, easy to back up or share in an interview).
