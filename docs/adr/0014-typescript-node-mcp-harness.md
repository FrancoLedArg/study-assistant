# TypeScript Node MCP harness (not a web app)

Study OS implements the **agent harness** in **TypeScript on Node**, as a stdio MCP server, because TypeScript is the operator’s default language, the MCP/Cursor reference path, and the agent-systems half of an AI Eng skillset (tools, MCP, durable memory) that a DS/AI degree does not already cover. Every user runs this on their own laptop, so the stack must not require compiling native addons (`node-gyp`) on that machine — SQLite must come from a Node built-in or a pure-JS package, not `better-sqlite3`. The LLM client stays replaceable; this lock is the harness implementation, not a first-party UI. Rejected: Python (despite FastAPI experience and stdlib sqlite3) — a second language here would duplicate school and lose the MCP-native path. Rejected: Next, Express, or any web framework in this repo — a later first-party client, if any, is a separate MCP client of this server, not a monolith that swallows the **student-model store** or **course packs**.
