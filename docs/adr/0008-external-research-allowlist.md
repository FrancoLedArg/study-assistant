# v1 external research tools and allowlist

Study OS locks external research for v1 as **web search only** (no Fetch-URL / HTML scrape tool — deferred for a compliance-aware pass). Search may run only after a **cátedra miss** (active pack `sources/` searched with no adequate hit) **or** an explicit learner request. Usable hits must match an **allowlist** of domains/URL prefixes: **harness-global defaults** plus optional **per-pack allow/deny overlays**; a pack cannot enable the whole web. Cited material is always an **external source** (labeled with type + URL/title), never silent model recall, and never written into `sources/` as cátedra. Concrete starter domain lists are config/operator choice, not part of this shape lock. Rejected for v1: autonomous page fetch, pack-only or harness-only allowlists without overlays, topic/keyword allowlists instead of URL prefixes, and skip-cátedra external use by default.
