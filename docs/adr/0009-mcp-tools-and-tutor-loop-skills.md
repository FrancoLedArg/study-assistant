# v1 MCP tools and tutor-loop skills

Study OS locks the v1 **agent harness** surface as a **closed capability set** for one complete **tutor loop** on one **course pack**. **Tools** are deterministic I/O only: load learner context (bootstrap, teaching profile, mastery, runtime registration, recent session summaries); search/read cátedra sources; allowlisted web search for external sources; write workspace artifacts; probe and (if present) run a registered subject runtime; submit a validated proposal with its evidence brief through the validator (the only student-model write path); write a session summary. **Skills** are choreography/guidance only — three in v1: tutor-loop (start→teach→artifacts→proposals→end), course-faithful teaching, and proposal hygiene. Pack `teaching/` notes are not extra harness skills. Exact tool names, parameter schemas, and full skill prose are out of this lock; so are Fetch-URL and runtime install. Rejected: unbounded tool matrix, free student-model writes, teach-as-a-tool, and packing pedagogy into MCP tools instead of skills.
